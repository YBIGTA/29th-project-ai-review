# 기초통계 대본 골드 평가 1차 결과

## 적용 조건

- 원문: 저장소 루트의 `기초통계_대본.txt`
- 평가 프로필: `basic_statistics_free_recall_demo_2min`
- 평가 방식: 사람이 rubric을 읽고 작성한 골드 판정 초안
- API 호출: 없음

원문은 279어절이다. 기존 1분 STT 대본이 65~87어절인 점을 기준으로 보면 약
3.2~4.3분 분량이므로 최대 2분 중간발표에서는 뒤쪽 내용이 잘릴 가능성이 높다.
아래 점수는 원문 전체가 전사되었다고 가정한 기능 테스트 결과다.

## 점수

| 평가항목 | 점수 |
|---|---:|
| 개념 정확도 | 17.26 / 40 |
| 핵심 개념 충족도 | 27.60 / 40 |
| 구조적 이해도 | 16.00 / 20 |
| 총점 | 60.86 / 100 |

## 잘 설명한 내용

- 가설 설정, 유의수준, 검정통계량, p-value, 기각 판단의 순서
- 공분산이 함께 움직이는 방향을 나타낸다는 설명
- 상관계수와 회귀분석이 제공하는 정보의 차이
- 잔차 플롯의 패턴을 회귀 가정 위반 신호로 보는 설명
- 이진 종속변수에서 로지스틱 회귀와 시그모이드를 사용하는 이유

## 주요 오류

- 분산을 `variable`이라고 표현하고 값이 클수록 안정적이라고 설명함
- 공분산 0을 완전한 독립으로 해석함
- 높은 상관관계를 인과관계 근거로 해석함
- p-value를 귀무가설이 참일 확률로 해석함
- 특정 95% 신뢰구간에 모수가 있을 확률을 95%라고 해석함
- 신뢰수준과 구간 폭의 트레이드오프를 무시함
- 높은 R²가 예측력과 인과성을 보장한다고 설명함

## 충족도와 구조 점수 해석

가설검정과 회귀 영역은 충분한 분량으로 다뤘지만 ANOVA 영역은 전혀 다루지 않아
핵심 개념 충족도에서 해당 영역 점수를 받지 못했다. 설명한 일부 개념은 틀렸지만
가설검정 절차와 상관·회귀 구분의 관계 구조 자체는 올바르게 표현되어 구조적
이해도 16점을 받았다. 잘못된 내용은 개념 정확도에서 감점되며 구조 점수에서
별도의 음수 감점은 하지 않는다.

## 중간발표 사용 전 조치

현재 원문을 그대로 사용하려면 녹음 제한을 3분 이상으로 두어야 한다. 최대 2분
데모를 유지한다면 실제로 읽어서 120초 시점의 전사문을 얻은 뒤, 그 전사문을
별도 골드 사례로 다시 판정하는 것이 가장 정확하다.
